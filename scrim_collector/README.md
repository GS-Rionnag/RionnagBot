# Optional scrim collector

Use its separate virtual environment and requirements.txt; discord.py-self conflicts with the main bot environment. Configure the private .env with DISCORD_USER_TOKEN and SCRIM_SOURCE_CHANNEL_IDS. The shared `python -m rionnag.service start|restart` supervisor automatically starts it and restarts it after crashes; `status` reports collector health and `stop` stops both runtimes. Do not start a separate collector from a chat. The feed defaults to ../data/scrim_feed.sqlite3; SCRIM_FEED_DB can override it. A feed lock prevents duplicates, and reconnect catches up missed history. Credentials and feed contents remain private. See ../docs/operations.md.
